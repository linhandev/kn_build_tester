### Service Calling

> For supported parameter and return value types and conversion rules, see the "Type Conversion" section

##### Kotlin Calling ArkTS Services

- 1、Declare interface as ServiceConsumer (Kotlin)

```Kotlin
@ServiceConsumer
interface TestServiceA {

    fun method1(str: String)

    fun method2(str: String): String?
}
```   

- 2、ArkTS Binding (ArkTS)

***Note: If obfuscation is enabled in Release, keep the ArkTS side ServiceProvider. For detailed obfuscation configuration see [Huawei Documentation](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/source-obfuscation-V5)***

```
import { registerServiceProvider, registerSingleServiceProvider } from "@kuiklybase/knoi"
//TestService is a custom ArkTS class
//TestService can implement d.ts files automatically generated by Ksp (generated in build/ts-api/), need to reference in Harmony project
registerServiceProvider("TestServiceA", /** singleton **/ false, TestService)
//Inject ArkTS singleton service as object
registerSingleServiceProvider("SingletonTestServiceA", new SingletonTestServiceAImpl())

```

- 3、Kotlin Calling (Kotlin)

KSP plugin will generate get{ServiceName}Api method after compilation, ServiceName is typically the class name if not customized
```Kotlin
getTestServiceAApi().method1("param1")
```

***Note: Service calling currently doesn't support ArkTS class static methods***

##### ArkTS Calling Kotlin Services

- 1、Declare ServiceProvider (Kotlin)

> Note: The class must be open and not Final

```Koltin

// Service name is typically the class name (without package), can specify singleton
@ServiceProvider
open class TestServiceB {

    fun method1(str: String) {
        info("TestServiceB method1 ${str}")
    }

}
```

- 2、ArkTS Calling (ArkTS)

> Note: getTestServiceB and interface definitions are automatically generated in build/ts-api/, need to reference in Harmony project

```ArkTS
// Calling method 1: Helper function
// Helper function generation rule get{ServiceName}, service name is typically class name if not customized
getTestServiceB().method1("param1")
// Calling method 2: Service name calling
getService<TestServiceB>("TestServiceB").method1("param1")
```

### Detailed Examples 🌰

##### Kotlin Calling ArkTS

Special type conversions:

1. JS callback parameters should be received as Array<JSValue>

2. JSValue can receive any type

```Kotlin
@ServiceConsumer
interface TestServiceA {
    // Pass Int return Int
    fun methodWithIntReturnInt(a: Int): Int
    // Pass Long return Long
    fun methodWithLongReturnLong(a: Long): Long
    // Pass Boolean return Boolean
    fun methodWithBooleanReturnBoolean(a: Boolean): Boolean
    // Pass Double return Double
    fun methodWithDoubleReturnDouble(a: Double): Double
    // Pass String return String
    fun methodWithStringReturnString(a: String): String
    // Pass Callback return Callback
    fun methodWithCallbackReturnCallback(a: (Array<JSValue>) -> Unit): ((Array<JSValue>) -> String)
    // Pass String array return String array
    fun methodWithArrayStringReturnArrayString(a: Array<String>): Array<String>
    // Pass JS object return JS object
    fun methodWithMapReturnMap(a: Map<String, Any?>): Map<String, Any?>
    // No parameters
    fun methodWithUnit()
    // Pass any JS type, return any JS type
    fun methodWithJSValueReturnJSValue(a: JSValue): JSValue
    // Pass ArrayBuffer binary data, return binary data
    fun methodWithArrayBufferReturnArrayBuffer(a: ArrayBuffer): ArrayBuffer?
    // Multiple parameters
    fun method3Params(a: String, b: Int, c: JSValue): JSValue
    // Return type is Promise, should be received as JSValue
    fun methodWithPromise(a:String): JSValue
}
```   

##### ArkTS Calling Kotlin

```kotlin
package com.tencent.tmm.knoi.sample

import com.tencent.tmm.knoi.annotation.Hidden
import com.tencent.tmm.knoi.annotation.ServiceProvider
import com.tencent.tmm.knoi.logger.info
import com.tencent.tmm.knoi.type.ArrayBuffer
import com.tencent.tmm.knoi.type.JSValue
import kotlinx.cinterop.ExperimentalForeignApi
import kotlinx.cinterop.set
import platform.posix.uint8_tVar
import kotlin.reflect.KClass

@ServiceProvider
open class TestServiceB {
    init {
        info("TestServiceB init.")
    }

    // Pass Int return Int
    fun methodWithIntReturnInt(a: Int): Int {
        return a + 1
    }

    // Pass Long return Long
    fun methodWithLongReturnLong(a: Long): Long {
        return a + 1
    }

    // Pass Boolean return Boolean
    fun methodWithBooleanReturnBoolean(a: Boolean): Boolean {
        return !a
    }

    // Pass Boolean return Double
    fun methodWithDoubleReturnDouble(a: Double): Double {
        return a + 0.1
    }

    // Pass String return String
    fun methodWithStringReturnString(a: String): String {
        return a + " modify from KMM"
    }

    // Pass callback return callback
    fun methodWithCallbackReturnCallback(a: (Array<JSValue>) -> Unit): ((Array<JSValue>) -> String) {
        a.invoke(arrayOf(ktValueToJSValue(getEnv(), "result", String::class)))
        return {
            "callback result"
        }
    }

    // Pass String array return String array
    fun methodWithArrayStringReturnArrayString(a: Array<String>): Array<String> {
        val list = a.toMutableList()
        list.add("plus in KMM")
        return list.toTypedArray()
    }

    // Pass JS object return JS object
    fun methodWithMapReturnMap(a: Map<String, Any?>): Map<String, Any?> {
        val map = a.toMutableMap()
        map["kmm"] = "push in KMM"
        return a.toMap()
    }

    // No parameter calling
    fun methodWithUnit() {
        info("TestServiceB methodWithUnit")
    }

    // Pass any JS type, return any JS type
    fun methodWithJSValueReturnJSValue(a: JSValue): JSValue {
        return a["json"]!!
    }

    // Pass binary data return binary data
    @OptIn(ExperimentalForeignApi::class)
    fun methodWithArrayBufferReturnArrayBuffer(buffer: ArrayBuffer): ArrayBuffer {
        info("methodWithArrayBufferReturnArrayBuffer")
        val bufferArray = buffer.getData<uint8_tVar>()
        bufferArray[4] = 4u
        bufferArray[5] = 5u
        bufferArray[6] = 6u
        bufferArray[7] = 7u
        return buffer
    }

    // Multiple parameters
    fun method3Params(a: String, b: Int, c: JSValue): JSValue {
        return c
    }

    // Hidden method, not generated to d.ts
    @Hidden
    fun method3(str: KClass<Any>): String {
        return "Hidden"
    }

    // private method, not generated to d.ts
    private fun method4(str: KClass<Any>): String {
        return "Hidden"
    }
}
```
